# Prioritized V1.5 work

1. **Evidence/rule audit:** verified current match fixtures, ordinary level/capacity rules, trait counting, Avatar and uniqueness rules, and hotfix parity. Resolve guide timing conflicts and stabilization cuts with human TFT review.
2. **Riot native adapter:** identity/history, credential isolation, real throttling, manual participants or verified official lobby discovery, cached-profile refresh, measured 10/20-game scanning.
3. **Measured strategy inputs:** simple family classification, versioned outcome collection, replace seeded features, calibrate confidence/portfolio weights, define evidence-promotion thresholds.
4. **Playbook depth:** source item alternatives, temporary holders, substitutions and pivot conditions. Validate variants and preserve core relationships before presenting them as useful.
5. **Team Planner:** verify mappings and a known-good Set 18 code, implement/test a codec, then require human paste into the actual TFT client before enabling Copy Team Code.
6. **Post-game UI:** import/associate completed matches, surface cautious end-state summaries, add sample-shrunk personal insights with 5% default influence.
7. **Release acceptance:** human visual/usefulness review, signed Windows installer and release smoke tests. Automated screenshots do not replace human acceptance.
