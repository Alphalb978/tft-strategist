# TFT Strategist

Private-first desktop TFT strategist focused on pre-game planning, fast opponent tendency analysis, three complementary comp recommendations, static in-game playbooks, Team Planner support, and post-game learning.

## Project status

Planning authority is being established before the first implementation milestone. See `AGENTS.md`, `docs/`, and `tasks/`.

## Core principle

TFT facts are data- and rule-authoritative. Models may implement and explain, but must not invent current-set rules, champion facts, Team Planner encoding, or strategic evidence.
